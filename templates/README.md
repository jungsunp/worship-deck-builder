# Templates

Put the master Keynote template here as `master.key`. It is **not committed**
(`.key` is git-ignored) because it is large and may contain church-specific media.

`master.key` is a **real recent deck** (native Keynote text boxes intact). Each week the
builder opens it, sets the changed text runs, and duplicates section slides to fit the
week's content — then saves a copy to `data/drafts/`. The template itself is left
unmodified.
